## 2. الأدلة (سبعة مؤشرات مستقلة)

### ① الهيكل النصّي = بصمة LLM كلاسيكية
كل ملف يتبع نفس القالب:
```
Chapter N: <عنوان>
• Definition: ...
• Scope: ...
• Importance: ...
• Mathematical Model – <اسم>
   <صيغة>
   Where:
   • P_i: probability of threat i
   • I_i: impact of threat i
   Note: This formula quantifies ...
```
هذا التركيب (تعريف ← نطاق ← أهمية ← «نموذج رياضي» ← `Where:` بقائمة رموز) هو **الشكل القياسي لمخرجات LLM**، ما تجده بهذا الانتظام بكتاب أكاديمي حقيقي.

### ② صفر مراجع — بكل الملفات
| الملف | `[n]` | قسم References | DOI | et al. |
|:---|:---:|:---:|:---:|:---:|
| **كل ملفات المحاضرات (14)** | **0** | **0** | **0** | **0** |

مادة أكاديمية حقيقية **لا تكون بلا مراجع**. الذكر الوحيد لـ NIST/ISO هو كأسماء جهات، بلا استشهاد.

### ③ معادلات «رياضية» ملفّقة
الملفات تعرض صيغاً تبدو رسمية لكنها **غير موجودة بأي كتاب**:
- `min R = Σ P_i·I_i − Σ C_j` (W01)
- `U(C,I,A) = αC + βI + γA` — «Security Utility Function» (W01)
- `PCI = Σ w_k·c_k / Σ w_k` — «Policy Compliance Index» (W01)
- `AS = Σ(E_j·V_j·A_j)` — «Attack Surface» (W01)
- `E_FL = Σ P_i·I_i` — «Expected Financial Loss» (W03)
- «Mathematical Model: Security Work Factor / Trust and Verification Framework» (W04)

> تحقّقت: «Policy Compliance Index» بهذي الصيغة **غير موجود** — الكتاب الوحيد القريب (Springer 2018) يستخدم نموذجاً مختلفاً تماماً (قائم على الموظفين). الصيغة **مُختَرَعة**، والصيغة تبدو «علمية» لتزيد مصداقية النص.

### ④ قوالب متكرّرة (Loop)
W07 (Malware) بنية متطابقة حرفياً لكل نوع:
`Viruses → How They Work → Example → Worms → How They Work → Example → Trojans → ...`
هذا **تكرار قالب** نموذجي بالـAI، مو شرح أكاديمي متكامل.

نمط عنوان مقالات الويب/الـAI، مو عنوان محاضرة جامعية.
