# 🔐 Cyber Security — Shortcuts & Abbreviations (الاختصارات)

> جدول بكل **الشورت كاتات (الاختصارات)** المستخدمة بملازم الأمن السيبراني. رتّبتها أبجدياً.
> المصدر: ملازم Week 01 + Week 02 + ملزمة الخطر (المستخرجة فعلياً من نصوص الملازم).
> Updated 2026-09-25.

| Shortcut | الاسم الكامل (English) | شنو يعني |
|---|---|---|
| **ACL** | Access Control List | قائمة تحكم بالوصول — تحدّد مين يكدر يوصل لأي مورد. |
| **AES** | Advanced Encryption Standard | معيار التشفير المتماثل الحديث (الأكثر استخداماً اليوم). |
| **APT** | Advanced Persistent Threat | تهديد متقدّم مستمر — هجوم منظّم وطويل الأمد يبقى داخل الشبكة خفية. |
| **AV** | Antivirus | مضاد الفيروسات — برنامج يكشف ويزيل البرمجيات الخبيثة. |
| **BCP** | Business Continuity Plan | خطة استمرارية العمل — تضمن استمرار العمل وقت الأزمات. |
| **CA** | Certificate Authority | جهة إصدار الشهادات — طرف موثوق يوقّع الشهادات الرقمية. |
| **CERT** | Computer Emergency Response Team | فريق الاستجابة لطوارئ الحاسوب — يتعامل مع الحوادث الأمنية. |
| **CIA** | Confidentiality, Integrity, Availability | الثالوث الأساسي لأمن المعلومات: السرية + السلامة + التوافر. |
| **CIRT** | Computer Incident Response Team | فريق الاستجابة للحوادث — يتحقق ويتعامل مع الاختراقات. |
| **COBIT** | Control Objectives for Information and Related Technologies | إطار حوكمة وإدارة تقنية المعلومات (تدقيق ورقابة). |
| **COSO** | Committee of Sponsoring Organizations | إطار للرقابة الداخلية وإدارة المخاطر على مستوى المؤسسة. |
| **CSF** | Cybersecurity Framework (NIST) | إطار الأمن السيبراني من NIST — خمس وظائف: تحديد/حماية/كشف/استجابة/تعافي. |
| **CVE** | Common Vulnerabilities and Exposures | قاعدة معرّفات عامة للثغرات المعروفة (مثل CVE-2024-XXXX). |
| **CVSS** | Common Vulnerability Scoring System | نظام تقييم خطورة الثغرات — يعطي درجة من 0 إلى 10. |
| **DDoS** | Distributed Denial of Service | هجوم إغراق **موزّع** من أجهزة كثيرة يوقف الخدمة. |
| **DLP** | Data Loss Prevention | منع تسرّب البيانات — يراقب ويمنع خروج البيانات الحساسة. |
| **DNS** | Domain Name System | نظام أسماء النطاقات — يحوّل الأسماء (مثل example.com) إلى عناوين IP. |
| **DoS** | Denial of Service | هجوم إغراق من مصدر واحد يمنع الوصول للخدمة. |
| **DRP** | Disaster Recovery Plan | خطة التعافي من الكوارث — كيف نرجّع الأنظمة بعد انهيار كبير. |
| **DSS** | Data Security Standard | معيار أمن البيانات (يأتي ضمن PCI-DSS لبطاقات الدفع). |
| **EDR** | Endpoint Detection and Response | كشف واستجابة على الأجهزة الطرفية (لابتوبات/سيرفرات) ضد التهديدات. |
| **ENISA** | European Union Agency for Cybersecurity | وكالة الأمن السيبراني للاتحاد الأوروبي. |
| **FAIR** | Factor Analysis of Information Risk | منهج كمّي لتقدير مخاطر المعلومات بالمال. |
| **GDPR** | General Data Protection Regulation | لائحة حماية البيانات الأوروبية — تحمي بيانات الأفراد. |
| **HIDS** | Host-based Intrusion Detection System | نظام كشف تسلل على مستوى **الجهاز** نفسه. |
| **HIPAA** | Health Insurance Portability and Accountability Act | قانون أمريكي لحماية خصوصية بيانات المرضى. |
| **HTTP** | HyperText Transfer Protocol | بروتوكول نقل صفحات الويب. |
| **IAM** | Identity and Access Management | إدارة الهويات والصلاحيات — مين يدخل على شنو. |
| **ICS** | Industrial Control Systems | أنظمة التحكم الصناعي (مصانع، محطات طاقة، مرافق). |
| **IDS** | Intrusion Detection System | نظام كشف التسلل — يراقب وينبّه على نشاط مشبوه. |
| **IEC** | International Electrotechnical Commission | الهيئة الدولية للتقانة الكهربائية (تشارك ISO بمعايير مثل 27001). |
| **IP** | Internet Protocol | بروتوكول الإنترنت — عنوان الجهاز داخل الشبكة. |
| **IPS** | Intrusion Prevention System | نظام منع التسلل — يكشف **ويمنع** الهجوم فوراً. |
| **ISMS** | Information Security Management System | نظام إدارة أمن المعلومات (جوهر معيار ISO 27001). |
| **ISO** | International Organization for Standardization | المنظمة الدولية للمعايير (تصدر ISO 27001 للأمن). |
| **IoT** | Internet of Things | إنترنت الأشياء — أجهزة متصلة (حساسات، كاميرات) تتواصل عبر الشبكة. |
| **MD5** | Message Digest 5 | خوارزمية تجزئة قديمة — صارت ضعيفة/مكسورة، ما تُستخدم للأمن. |
| **MFA** | Multi-Factor Authentication | مصادقة متعددة العوامل — شي تعرفه + شي تملكه + شي تكونه. |
| **MITM** | Man-in-the-Middle | هجوم "رجل في المنتصف" — يعترض الاتصال بين طرفين ويسرق/يعدّل البيانات. |
| **MTBF** | Mean Time Between Failures | متوسط الزمن بين الأعطال — مقياس موثوقية النظام. |
| **MTTR** | Mean Time To Repair / Recover | متوسط زمن الإصلاح/التعافي — شكد ياخذ وقت للرجوع بعد عطل. |
| **NIDS** | Network-based Intrusion Detection System | نظام كشف تسلل على مستوى **الشبكة**. |
| **NIST** | National Institute of Standards and Technology | معهد أمريكي يصدر أطر الأمن (NIST CSF, RMF, SP 800-xx). |
| **OCTAVE** | Operationally Critical Threat, Asset, and Vulnerability Evaluation | إطار لتقييم المخاطر الأمنية على مستوى المؤسسة (تركيز على الأصول الحيوية). |
| **OWASP** | Open Worldwide Application Security Project | مشروع مرجعي لأمن تطبيقات الويب (أشهرها OWASP Top 10). |
| **PCI (DSS)** | Payment Card Industry Data Security Standard | معيار أمن بيانات بطاقات الدفع — إلزامي لأي جهة تتعامل ببطاقات. |
| **PDCA** | Plan–Do–Check–Act | دورة التحسين المستمر: خطّط ← نفّذ ← تحقّق ← صحّح. |
| **PKI** | Public Key Infrastructure | البنية التحتية للمفتاح العام — شهادات + جهات إصدار + مفاتيح. |
| **RBAC** | Role-Based Access Control | صلاحيات حسب **الدور الوظيفي** (مدير/موظف/زائر). |
| **RFID** | Radio Frequency Identification | تعريف بالترددات الراديوية — بطاقات/تاقات تُقرأ لاسلكياً. |
| **RMF** | Risk Management Framework | إطار إدارة المخاطر (من NIST) — دورة إدارة المخاطر المؤسسية. |
| **RPO** | Recovery Point Objective | هدف نقطة التعافي — أقصى قدر بيانات مقبول نخسره (بالزمن). |
| **RSA** | Rivest–Shamir–Adleman | خوارزمية تشفير **غير متماثل** (مفتاح عام/خاص). |
| **RTO** | Recovery Time Objective | هدف زمن التعافي — أقصى زمن مقبول للرجوع بعد توقف. |
| **SCADA** | Supervisory Control and Data Acquisition | نظام إشراف وتحكم — يراقب ويتحكم بالأنظمة الصناعية. |
| **SHA** | Secure Hash Algorithm | خوارزمية تجزئة آمنة (SHA-256...) — للتحقق من السلامة. |
| **SIEM** | Security Information and Event Management | جمع وتحليل أحداث الأمن مركزياً — لوحة موحّدة للتنبيهات. |
| **SOC** | Security Operations Center | مركز عمليات الأمن — فريق يراقب 24/7. |
| **SQL** | Structured Query Language | لغة قواعد البيانات (تُستغل بـSQL Injection). |
| **SQLi** | SQL Injection | حقن أوامر SQL — ثغرة تسمح بالوصول/التلاعب بقاعدة البيانات. |
| **SSL** | Secure Sockets Layer | بروتوكول تشفير قديم — استُبدل بـTLS. |
| **TCP** | Transmission Control Protocol | بروتوكول نقل موثوق (طبقة النقل) — يضمن وصول البيانات بالترتيب. |
| **TLS** | Transport Layer Security | بروتوكول تشفير الاتصالات الحديث (خليفة SSL). |
| **VPN** | Virtual Private Network | شبكة خاصة افتراضية — نفق مشفّر للاتصال الآمن عن بُعد. |
| **WAF** | Web Application Firewall | جدار ناري لحماية تطبيقات الويب من هجمات مثل XSS وSQLi. |
| **XDR** | Extended Detection and Response | كشف واستجابة موسّع — يربط الشبكة + الأجهزة + السحابة. |
| **XSS** | Cross-Site Scripting | حقن سكربتات ضارة بصفحات الويب لتُشغَّل عند المستخدمين. |

## ➕ اختصارات شائعة (ما لقيتها بملازمك الحالية — للمعرفة)

| Shortcut | الاسم الكامل | شنو يعني |
|---|---|---|
| **AAA** | Authentication, Authorization, Accounting | المصادقة + التصريح + المحاسبة — يترافق مع CIA. |
| **IoC** | Indicator of Compromise | مؤشر اختراق — أثر يدل على وجود تهديد. |
| **OSI** | Open Systems Interconnection | نموذج الطبقات السبع للشبكات. |
| **NAT** | Network Address Translation | ترجمة عناوين الشبكة (يخفي IP الداخلي). |
| **SSO** | Single Sign-On | تسجيل دخول واحد لكل الأنظمة. |
| **2FA** | Two-Factor Authentication | مصادقة بعاملين. |
| **PII** | Personally Identifiable Information | معلومات تعريف شخصية. |
| **BYOD** | Bring Your Own Device | جيب جهازك الخاص للعمل. |
| **MAC** | Mandatory Access Control | تحكم وصول إلزامي (مقابل RBAC/ACL). |
| **TTP** | Tactics, Techniques, and Procedures | تكتيكات وأساليب وإجراءات المهاجم. |
