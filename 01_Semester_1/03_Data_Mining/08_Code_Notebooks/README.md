### Why this notebook exists

The lecture handout is a **definition** document: it says what each algorithm is, when to use it
and what it costs, but it never shows the fitting machinery. The notebook closes that gap:

* every closed-form formula (normal equations, ridge closed form, ε-insensitive loss, MAE/MSE/RMSE/R²,
  VIF, Durbin–Watson, Newey–West/HAC SEs) is written out **by hand in code** and then cross-checked
  against `scikit-learn` — a mismatch raises, so the notebook cannot silently go wrong;
* every worked example in the PDF is reproduced numerically (the lecture's own numbers come back out
  of the code);
* every "limitations" table row is **made to happen** on screen: omitted-variable bias,
  autocorrelation, heteroscedasticity, multicollinearity, overfitting, underfitting, outliers,
  data leakage, distribution shift;
* 35 figures, each followed by an interpretation cell that says what the plot *proves*.

### ⚠️ One verified error in the lecture handout

`تنقيب البيانات - الجابتر التاسع.pdf` §3.2 prints

```
ŷ = 50 + 20(15) + 10(3) − 5(4) = 340
```

but the arithmetic gives **360** (50 + 300 + 30 − 20). The lecture's own interpretation of the
coefficients (+$20,000 / +$10,000 / −$5,000) matches the **coefficients**, so the correct predicted
price is **$360,000**. Notebook §8.1 recomputes the line term by term and flags the slip; the
erratum is repeated in the §21 exam cheat-sheet.

## Retrieval set — six questions to check that you read it

1. **Write the least-squares normal equation and the closed-form slope.**
   $\hat\beta = (X^\top X)^{-1}X^\top y$ and
   $\hat\beta_1 = \dfrac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}$,
   with $\hat\beta_0 = \bar y - \hat\beta_1\bar x$. *(Notebook §5, cells 5.1 / 5.4.)*
2. **The lecture's §3.2 house-price example: what is the predicted price, and what is wrong
   with the handout?** $50+20(15)+10(3)-5(4) = 360$ → **$360,000**; the handout prints 340.
   *(Notebook §8.1.)*
3. **Why does Ridge shrink coefficients but Lasso delete them?**
   The L2 penalty has a smooth surface (the optimum is never on an axis), the L1 penalty has
   corners (the optimum often lands exactly on an axis, so $\hat\beta_j = 0$). *(Notebook §10.)*
4. **Name the four residual diagnostics the handout asks for, and what each one is looking for.**
   Residuals-vs-fitted (curvature → nonlinearity; funnel → heteroscedasticity), Q–Q plot
   (normality), residuals in observation order (dependence/autocorrelation), correlation matrix +
   VIF (multicollinearity). *(Notebook §7.)*
5. **A model has training RMSE 2.1 and test RMSE 6.8. What is it, and how do you fix it?**
   Overfitting — the model memorised training noise. Simplify, regularise (Ridge/Lasso), prune
   trees, select the model by cross-validation. *(Notebook §19–§20.)*
6. **Why must the scaler be fitted on the training data only?**
   Fitting it on train+test lets test information enter training (data leakage) and inflates the
   test score. The fix is a `Pipeline`, which enforces it mechanically. *(Notebook §16.)*
