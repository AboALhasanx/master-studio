## 5. موضوع «3 مواد بمادة» — التداخل الحقيقي وين

| الموضوع | بالـ **AI** | بالـ **Data Mining** | بالـ **Soft Computing** |
|:---|:---|:---|:---|
| **KNN** | مصنِّف + قرار + تقييم | **مقياس التشابه/المسافة** (`W03_Feature_Extraction`) | — |
| **SVM** | هامش + kernels + دعم | **اختيار الميزات** قبله (`Feature_Selection_Techniques`) | — |
| **Naive Bayes** | احتمال + استقلال شرطي | — | — |
| **GA** | — | — | ✅ بالخط (`Soft Computing`) |
| **NN** | ضمن Deep Learning | — | ✅ بالخط |

**الحكم:** مو ثلاث مواد — مادة وحدة **بثلاث زوايا**. AI يسألك «شلون يقرر ويصنّف»، DM يسألك «شلون تجهّز البيانات وتختار الميزة وتقيس المسافة»، Soft Computing يسألك «شلون تتعلّم الشبكة/يتطور الحل». نفس الخوارزمية، **سؤال مختلف** كل مرة.

**⚠️ دقة مهمة:** التفريغ ذكر **Soft Computing** فقط («Soft Computing: Genetic Algorithm و Neural Networks») — **ما ذكر Data Mining**. فإذا الدكتور كالها بالصف، هي مو بالتفريغ اللي عندي. لا أبني عليها خطة إلا تتأكد.

**الخطر العملي:** تدرس نفس الشي ثلاث مرات بثلاث صياغات وتتعب بلا فايدة. **الحل:** ندرسه مرة وحدة بعمق (بهذا العرض)، وبعدين نسوي «بطاقة تحويل» صغيرة لكل مادة تختصر الفرق بالأسئلة.

## 6. خطة العمل — 5 مراحل

**المرحلة 1 — قفل المصدر (بلا كتابة).**
أقرأ §19.7 + SVM + NB من AIMA، وأطلع: تعريف كل خوارزمية، المعادلة، شروط الاستخدام، نقاط الضعف. **ممنوع نكتب سلايد قبل نخلص هالمرحلة.**

**المرحلة 2 — الأمثلة الرقمية (هذا اللي طلبه الدكتور).**
- **KNN:** مجموعة 2D صغيرة (6–8 نقاط، صنفين) → احسب المسافات → رتّب → k=3 → تصويت → القرار + حدود القرار.
- **Naive Bayes:** جدول صفات (طقس/حرارة/رطوبة) → prior + likelihood → posterior → **Laplace smoothing** لتفادي الصفر.
- **SVM:** نقاط قابلة للفصل → الهامش → متجهات الدعم → معادلة المستوي → ثم kernel trick **مفهومياً** (بلا اشتقاق، لأن الدكتور ما يطلب اشتقاق).

**المرحلة 3 — بناء العرض.** 18–22 سلايد: العنوان ← ML taxonomy ← Supervised vs Unsupervised ← Classification pipeline ← KNN (3–4) ← NB (3–4) ← SVM (4–5) ← مقارنة ← متى نستخدم أيها ← أخطاء شائعة ← خلاصة ← مراجع. **إنكليزي**، صور/مخططات، بلا كود ASCII.

**المرحلة 4 — التدريب الشفهي.** تشرح كل خوارزمية بـ3 دقائق بكلامك، وأنا أسألك أسئلة الدكتور المتوقعة: «ليش k وتر؟» «شو يصير لو k=n؟» «ليش NB يسمّى naive؟» «SVM خطي vs non-linear؟» «ليش نطبّع المسافات؟»
