# البحث — BFS إلى A\*

> غطِّ عمود **الجواب**، اقرأ السؤال، قل الجواب بصوت عالٍ، ثم اكشف. علّم ✓ أو ✗ — **وما لم يُعلَّم ✓ هو قائمة الغد**.
> **صيغة د. سيف:** تتبّع كامل · **الـfrontier بكل خطوة** · بلا اشتقاق

## الصيغ

| الصيغة | المعنى |
|:---|:---|
| $f(n) = g(n) + h(n)$ | تقدير كلفة المسار الكامل عبر $n$ |
| $h(n) \le h^*(n)$ | **Admissibility** — شرط الأمثلية |
| $h(n) \le c(n,n') + h(n')$ | **Consistency** — أقوى، وتضمنها |

**المثال المحسوب:** على `S←A←B←G` يكون $g = 0,1,2,3$ و$h = 1,1,1,0$، فـ$f = 1,2,3,3$. تُوسَّع B قبل D لأن $f(B)=3 < f(D)=6$، والمسار الأمثل **3**. وبـBFS نفس المخطط يعطي **11** — لأنه يعدّ الحركات لا الكلفة.
