# Unit 1 — What makes someone a hero?

> **سؤال الوحدة:** شنو يخلّي شخصاً بطلاً؟

## 4. القاعدة — Restrictive Relative Clauses

> **في سطر:** who/that للأشخاص، which/that للأشياء. الضمير يُحذف فقط إذا كان **مفعولاً** داخل الجملة النسبية.

| النوع | التركيب | مثال |
|:--|:--|:--|
| Subject relative | who/that + فعل | A hero is someone **who embodies** good qualities. |
| Object relative | who/that/which + فاعل + فعل | The book **that I bought** was expensive. |
| Object relative + حذف | Ø + فاعل + فعل | The book **I bought** was expensive. |

| ❌ خطأ | ✅ صحيح | السبب |
|:--|:--|:--|
| The man **which** helped me. | **who/that** | شخص |
| The book **who** I read. | **which/that** | شيء |
| The man **who he** helped me. | **who helped me** | لا نكرر الفاعل |
| The man **lives** next door is a doctor. | **who lives** | الضمير فاعل |

## 5. الكتابة — Analysis Paragraph

**الهيكل:**

1. **Topic sentence** — فكرة رئيسية + controlling idea.
2. **Supporting sentences** — سبب + مثال + تفصيل.
3. **Concluding sentence** — إعادة صياغة + خلاصة.

**مثال topic sentence:**
> A hero is not defined by superpowers, but by the willingness to act for others.

**الروابط:** First · Second · For example · In addition · Most importantly · Finally.

## ✎ أسئلة — استرجاع سريع

1. شنو الفرق بين البطل الخارق والبطل الحقيقي؟
2. اذكر 3 صفات من Five Cs؟ (إذا درستها بالوحدة)
3. متى نحذف relative pronoun؟
4. شنو وظيفة topic sentence؟
5. اكتب جملة فيها object relative clause واحذف الضمير.

**إجابات نموذجية:**

- **1.** الخارق عنده قوى خارقة؛ الحقيقي عنده قرار وتضحية وتأثير، وقواه بشرية.
- **2.** الصفات: competence · confidence · connection · character · caring (أي ثلاث).
- **3.** عندما يكون الضمير **مفعولاً** داخل الجملة النسبية، والجملة عندها فاعل خاص.
- **4.** تحدد الفكرة الرئيسية + controlling idea للفقرة.
- **5.** نموذج: The book **I bought** yesterday was expensive.
