## القواعد الذهبية

1. **لا تحفظ الجواب قبل ما تفهم "ليش".** كل جواب عنده سطر `ليش؟`.
2. **كل جواب له دليل.** إذا ما لقيت الدليل بالكتاب، الجواب يتوسم **نموذج**.
3. **القراءة أولاً، التمرين ثانياً.** لا تبدأ بالأسئلة قبل ما تقرأ الملخص.
4. **الكتابة عملية، مو قالب.** الموديل مثال، مو نص تحفظه.
5. **المراجعة بالاسترجاع.** غطِّ الجواب وحاول، بعدها تحقق.
