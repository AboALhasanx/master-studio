## 2. الخطوة 1 — جرد التمارين (قبل أي قصّ)

**لا تفترض.** استخرج كل تعليمة تمرين آلياً بأفعال الأوامر، ثم اقرأ قائمة **شارات الحروف** A/B/C:

```python
import pymupdf, re
d = pymupdf.open(PDF)
VERBS = r'(Read|Answer|Circle|Complete|Discuss|Write|Highlight|Choose|Look|Draw|Think|Listen|Compare|Find|Name|Underline|Preview|Describe|Give|Rewrite|Check|Review|Brainstorm|Outline|Revise)'
for i, p in enumerate(d, start=1):
    for ln in p.get_text().splitlines():
        if re.match(r'^[A-Z]?\.?\s*' + VERBS + r'\b', ln.strip()) and len(ln.strip()) > 18:
            print(f"p{i:02d}: {ln.strip()[:100]}")

# شارات A/B: حرف مفرد (+نقطة اختيارية) بعمود يسار، عرضه < 20
for i, p in enumerate(d, start=1):
    hits = [ (round(w[1],1), w[4]) for w in p.get_text("words")
             if re.fullmatch(r"[A-Ha-h]\.?", w[4].strip()) and w[0] < 210 and (w[2]-w[0]) < 20 ]
    if hits: print(f"p{i:02d}: {sorted(hits)}")
```

**القاعدة:** كل **A** و**B** و**C** = **شريحة مستقلة**. (طلب الطالب صراحةً: *"لو التمرين بيه A و B افصلها لكل واحد وحده كأنها تمارين مختلفة"*.)

**تحذير من التجربة:** التمارين تكمل على الصفحة التالية — `e01` (أسئلة الوحدة 2 و3) و`e14` (MAIN IDEAS 2-4) و`e23` (خطوات Brainstorm) كلها كانت مقطوعة لأن آخر مرسى اخترته لم يكن آخر سطر فعلاً. **حدّد آخر سطر من جرد الصفحة، مو من حدسك.**

## 3. الخطوة 2 — حدود كل تمرين

لكل تمرين (أو جزء A/B) حدّد: `(رقم الصفحة في الملف المركّز، y_البداية، y_النهاية)` — وقد يكون **عدة مقاطع** إذا التمرين ممتد على صفحتين.

**قواعد ضبط الحدود:**

| القاعدة | السبب |
|:--|:--|
| **ابحث عن المراسي بـ`page.search_for`** لتحديد أول/آخر سطر | أدق من التخمين |
| **اترك هامشاً 8-10 نقاط** فوق وتحت | يغطي انزياح OCR |
| **`BOTTOM_LIMIT` مرتفع بما يكفي** (هنا **712**) | آخر سطر بص29 يصل ~705 |
| **ثم اضبط يدوياً** بين آخر سطر والتذييل | حتى لا يدخل `| Reading and Writing 51` |
| **لا تجعل المقطع الأول ينتهي داخل القسم التالي** | وإلا يدخل عنوان القسم التالي بالصورة |

## 4. الخطوة 3 — المولّد (القلب)

**الخوارزمية الصحيحة — انسخها كما هي:**

```python
import numpy as np, pymupdf
from PIL import Image

DPI          = 300
INK          = 200   # رمادي أقل منه = حبر مطبوع
MIN_INK      = 3     # بكسل حبر مطلوب بالصف/العمود قبل أن يُحتسب
TRIM_PAD     = 14    # هامش يُترك حول صندوق الحبر
SNAP_SEARCH  = 12    # أقصى بحث عن صف فارغ (نقاط)
EDGE_IGNORE  = 27    # شريط الحافة الخارجي: قد يكون حافة سكان أو تبويب صفحة
GAP          = 14    # فراغ بين مقاطع مخيطة
scale = DPI / 72.0


def crop_segment(page, y0, y1, tx0=None, tx1=None):
    """قصّ مقطع واحد: الحدّ يهبط على أقرب صف فارغ."""
    top_pt = max(0.0, y0 - SNAP_SEARCH)
    bot_pt = min(page.rect.height, y1 + SNAP_SEARCH)
    pix = page.get_pixmap(clip=pymupdf.Rect(0, top_pt, page.rect.width, bot_pt), dpi=DPI)
    im  = Image.frombytes("RGB", (pix.width, pix.height), pix.samples)
    grey = np.asarray(im.convert("L"))
    H, Wpx = grey.shape

    # ⚠️ الفراغات تُقاس بعمود النصّ فقط — صورة ممتدة تلمس كل صف وتخفي كل فراغ
    if tx0 is not None and tx1 and tx1 > tx0:
        prof = (grey[:, max(0, int(tx0*scale)):min(Wpx, int(tx1*scale))] < INK).sum(axis=1)
    else:
        prof = (grey < INK).sum(axis=1)
    blank = prof <= 1

    def nearest_blank(r):
        """الأقرب، لا الأبعد: المشي باتجاه واحد يسحب السطر المجاور كاملاً."""
        r = max(0, min(H - 1, r))
        for d in range(0, int(SNAP_SEARCH * scale) + 1):
            if r - d >= 0 and blank[r - d]: return r - d
            if r + d < H  and blank[r + d]: return r + d
        return r

    t = nearest_blank(int((y0 - top_pt) * scale))
    b = nearest_blank(int((y1 - top_pt) * scale))
    if b <= t: t, b = 0, H - 1

    # الأعمدة: مجموع الحبر داخل نطاق الصفوف المختار
    # ⚠️ باگ وقعت فيه: قصّ العمود بمؤشرات الصف (colink[t:b+1]) يعطي شرائح بعرض 28 نقطة
    m = min(int(EDGE_IGNORE * scale), Wpx // 4)
    band = (grey[t:b + 1] < INK)
    cols = np.nonzero(band[:, m:Wpx - m].sum(axis=0) > 0)[0]
    l, r = (int(cols[0]) + m, int(cols[-1]) + m) if len(cols) else (0, Wpx - 1)
    l, r = max(0, l - TRIM_PAD), min(Wpx, r + TRIM_PAD)

    im = im.crop((l, t, r, b + 1))
    return im, {"page": page.number + 1, "x0": l/scale, "x1": r/scale,
                "y0": top_pt + t/scale, "y1": top_pt + (b + 1)/scale}
```

**تخييط المقاطع** (تمرين على صفحتين): الصق عمودياً على خلفية بيضاء بفراغ `GAP`.

**سجّل `crop_boxes.json`** — كل صندوق بإحداثيات الـPDF. يخلي الصور **قابلة للتدقيق بلا إعادة رسم**.

## 6. قالب الشرائح (HTML)

- **صفحة واحدة**، `dir="rtl"`، خلفية **فاتحة** (الصور مسح أبيض — الخلفية الغامقة تبدو سيئة).
- كل شريحة: `<section class="slide">` ← ترويسة (رقم + عنوان إنجليزي + مرجع الصفحة) ← `.split` بمصفوفة **`1fr / 1.05fr`**.
- **⚠️ RTL:** العنصر الأول يُرسم **على اليمين** ⇒ `.shot` (التمرين) **يمين** و`.sol` (الحل) **يسار**. (أول نسخة من نص الترويسة قالت العكس ووجب تصحيحها.)
- الحل: جداول `class="sol"` + `p.key` (صندوق ذهبي للحل النهائي) + `p.note` (ملاحظة عربية).
- **الطباعة:** `@media print { @page { size: A4 landscape; margin: 10mm } ... }`.
