Dr. Ali Fahim's Top Exam Traps

Avoid These Common Mistakes on the Software Planning Exam

⚠️ Trap 1: VAF Formula Constant

Fatal Mistake: Writing 0.65 + 0.1 × TDI instead of 0.01.

Correct: VAF = 0.65 + 0.01(48) = 1.13
Wrong: 0.65 + 0.1(48) = 5.45 (Invalid!)
⚠️ Trap 2: Language Sizing Fallacy

Fatal Mistake: Assuming a system coded in C has more Function Points than in Python.

FP is 100% language-independent!
Only LOC changes, FP remains invariant.
⚠️ Trap 3: Inquiry vs Transaction

Fatal Mistake: Classifying an inquiry with derived calculations as an EQ instead of an EO.

EQ = Pure retrieval without formulas.
EO = Contains calculated / derived values.
