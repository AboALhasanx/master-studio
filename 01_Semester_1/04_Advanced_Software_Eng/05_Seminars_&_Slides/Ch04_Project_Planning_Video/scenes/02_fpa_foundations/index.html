Allan Albrecht & The Function Point Revolution

1979 IBM Breakthrough: Measuring Software from the User's Perspective

👨‍💼
Allan J. Albrecht
IBM Corporation
1979 Formulation
The Fundamental Paradigm Shift
Albrecht realized that traditional software estimation made the fatal mistake of measuring developer artifacts (LOC) rather than the actual functional value delivered to the user.
❌ Old LOC Mindset
How many syntax lines did the developer write? (Implementation-biased)
✅ Albrecht FPA Mindset
What functional business capabilities does the user receive? (User-visible)
💡
Historical Milestone (Aggarwal & Singh Ch.4)
Function Point Analysis (FPA) established the world's first programming-language-independent software sizing metric.
أسس تحليل نقاط الوظيفة (FPA) أول مقياس عالمي لقياس حجم البرمجيات بمعزل تام عن لغة البرمجة المستخدمة.

Early Estimation from Requirements (SRS)

How FPA enables cost and schedule modeling before development starts

1. SRS Requirements Input
Functional specifications, use cases, inputs, outputs, data stores.
المتطلبات الوظيفية وحالات الاستخدام وجداول البيانات.
➔
2. Function Point Analysis Core Metric
Categorize and weight the 5 Standard Components (EI, EO, EQ, ILF, EIF).
تصنيف ووزن المكونات الوظيفية الخمسة الأساسية.
➔
3. Effort & Schedule Output
Predict Person-Months (PM) and delivery timeline early in planning!
تقدير الجهد والجدول الزمني في المراحل الأولى للتخطيط.
🎯
Why FPA Solves the Planning Vacuum
Because FPA relies exclusively on external functional requirements (SRS), sizing can be performed in week 1 of the project before a single line of source code is typed.
نظراً لأن نقاط الوظيفة تعتمد كلياً على المتطلبات الوظيفية (SRS)، يمكن حساب الحجم في الأسبوع الأول للمشروع وقبل كتابة سطر كود واحد.

Language Independence & Sizing Consistency

Comparing LOC variance against constant Function Point delivery

Same Functional System Across Languages Constant FP
Language / Platform Lines of Code (LOC) Function Points (FP)
Assembly Language ~320,000 LOC 1,000 FP
C / C++ ~128,000 LOC 1,000 FP
Java / C# ~53,000 LOC 1,000 FP
Python / Modern 4GL ~20,000 LOC 1,000 FP
Key Pedagogical Takeaways Mastery
  • 💎
    Invariant Size: Function Points remain 1,000 FP regardless of tech stack.
  • 📊
    Gear Ratio: Modern languages require fewer LOC per FP (LOC / FP).
  • 🚀
    Next Step: Understanding the 5 standard FPA components (ILF, EIF, EI, EO, EQ).
