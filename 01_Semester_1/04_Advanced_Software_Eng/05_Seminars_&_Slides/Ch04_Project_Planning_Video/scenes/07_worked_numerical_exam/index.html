Step 2: Calculate VAF & Final Adjusted Function Points

Applying Technical Complexity Adjustment to Raw Functional Size

1
Compute Value Adjustment Factor (VAF)

Sum of 14 General System Characteristics: TDI = ∑ Fi = 48
(Reflecting high requirements for data communications, security, and distributed processing).

VAF = 0.65 + (0.01 × TDI)
VAF = 0.65 + (0.01 × 48) = 0.65 + 0.48 = 1.13

Result indicates a +13% adjustment for technical complexity.

2
Calculate Final Adjusted FP

Multiply Unadjusted Function Points by the Value Adjustment Factor:

Adjusted FP = UFP × VAF
FP = 154 × 1.13 = 174.02 Function Points
Key Takeaway: Functional size grew from 154 to 174.02 to account for stringent non-functional reliability requirements.
