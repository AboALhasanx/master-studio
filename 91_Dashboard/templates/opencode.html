Slash commands — how they work

Type /name args in the TUI. Any .opencode/commands/*.md file becomes /filename.

.opencode/commands/review.md
---
description: Review code for correctness
agent: plan
model: anthropic/claude-sonnet-4-5#high
subagent: true
---
Review $ARGUMENTS for bugs and missing tests.
PlaceholderMeaning
$ARGUMENTSFull argument string as typed
$1, $2…Positional args (quotes group words)
!`cmd`Shell output inserted before submit
subagent: trueRun in background child session

Built-in slashes & palette

Press Ctrl+P for the command palette — every slash, keybind command, and plugin command lives there. Confirmed built-ins:

Slash / actionWhat it does
/diffDiff viewer (branch / committed / working)
/mcpsMCP servers — select one to sign in (OAuth)
@agentMention a subagent directly in prompt
Ctrl+P → Open settingsEdit common cli.json settings live
Ctrl+P → ExperimentsToggle experimental feature IDs

Settings — two files, two owners

FileOwns
opencode.json(c)Server: model, agents, permissions, MCP, providers, commands, plugins
cli.jsonTUI only: theme, tabs, session view, diffs, attention, keybinds, TUI plugins

cli.json groups: theme, session (sidebar/scrollbar/thinking/markdown), tabs (mode/scope/layout), diffs (source/wrap/view), attention (notifications/sound), keybinds, plugins (TUI-only!), mini, debug.

Rule: server-only plugins (tools, no ./tui export) go in opencode.json → plugins, never in cli.json — that was your quota crash.
