### 12. TOOL BUG FOUND — `quiz_balancer.py --strict` (IMPORTANT, reusable)
- **`--strict` shuffles the option arrays but does NOT recompute `correct`/`answer`.** After it runs, the marked letter no longer points at the semantically correct option. Measured: **14/30 desynced** on the first W2 build.
- It also shuffles **`options_ar` independently** of `options_en` → the Arabic mirror ends up in a different order than the English (bilingual desync).
- **Fix / standing rule:** do NOT use `--strict` as a rebalancing step. Instead, set the balanced key pattern **in the builder itself** (rotate the three option lists together and compute `correct` from the rotation), then run `--strict` **only on a throwaway copy** as a balance report. Never let it rewrite the deliverable.
- Rotation math that works: to make `new[want] == old[ci]` use `new[j] = old[(j - want + ci) % 4]` (NOT `j - ci + want`, which is the inverse).
