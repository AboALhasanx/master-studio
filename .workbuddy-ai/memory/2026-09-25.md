## ✅ DM deep-dive v4.2 — fixed the RTL/LTR bug for nested verbatim quotes (ENGINE fix)

Student (with screenshot): the English verbatim lines still render **RTL** — `**W2 P7** "TF-IDF(t,d) = ..."` shows as `"TF(t,d) × IDF(t) = )t,d(TF-IDF" W2 P7` (label/quote reordered + parentheses mirrored). They are pure English, so they must be **LTR**. Asked for **v4.2**.

**🔴 ROOT CAUSE (in the shared engine, not the note):** `pdf_exporter.py → tag_bilingual_blocks()`. Its regex `<(h[1-6]|p|blockquote|li|table)…>(.*?)(</\1>)` matched the **outer** Arabic container first — for a card, the verbatim `<blockquote>` sits **inside** the `<li>` of the `- شنو هو:` bullet — and the match **consumed** the inner English blockquote, so it never received `dir="ltr"` and inherited RTL. Top-level quotes were fine; only quotes nested inside a list item broke. (Same defect hits section 6.8's nested quotes.)

**Fix (engine):** made `_fix_tag` **recurse** into its own content before deciding, so nested blocks are tagged independently of the outer container:
```python
pattern = r'<(h[1-6]|p|blockquote|li|table)(\s*[^>]*)>(.*?)(</\1>)'
def _fix_tag(m):
    tag, attrs, content, closing = m.group(1), m.group(2) or "", m.group(3), m.group(4)
    content = re.sub(pattern, _fix_tag, content, flags=re.DOTALL)   # <-- the fix
    if 'dir=' in attrs: return f'<{tag}{attrs}>{content}{closing}'
    inner = re.sub(r'<[^>]+>', '', content)
    if inner.strip() and not has_arabic(inner):
        return f'<{tag}{attrs} dir="ltr" class="ltr-block">{content}{closing}'
    return f'<{tag}{attrs}>{content}{closing}'
```
The change is **additive** (only adds `dir="ltr"` to nested PURE-English blocks; Arabic blocks untouched). Regression-checked the pipeline on v3 + 2 Cyber notes → no crash, sane `ltr-block` counts.

**Second defect fixed (source):** the Density verbatim `"Density = 2*|E| / (|V|*(|V|-1))"` lost its `*` to markdown **emphasis** (rendered `2|E| / (|V|(|V|-1))`). Fixed by escaping → `2\*|E| / (|V|\*(|V|-1))` (renders `*` literally, verbatim preserved).
