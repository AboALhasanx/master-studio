# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(v2.1). In short: be respectful, be constructive, no harassment.

## Enforcement

Violations can be reported privately via the channel described in
[SECURITY.md](SECURITY.md). The maintainer will review and respond within
14 days and may remove offending content or restrict participation.
