## 3. ما هو مُنجز ومُثبت لايف ✅

- **البنية الأساسية:** `schema.py` (نحو Pydantic للأوامر)، `acl.py` (قائمة سماح المالك + بوابة `--confirm` للأفعال المدمّرة)، `store.py` (طابور SQLite + idempotency + سجل تدقيق + rate limiter + backoff)، `transport.py` (`MockTransport` + `HttpTransport` بلا `getUpdates`)، `executor.py` (ترخيص → حلّ → منع تكرار → تحديد معدّل → إرسال → تدقيق).
- **التنظيم الحيّ للجروب:** 10 توبيكات مُنشأة بواسطة البوابة نفسها + كارت مثبّت لكل توبيك + فهرس مثبّت بأزرار في General؛ **إعادة التشغيل = لا شيء (`created: []`، كلها duplicate)**.
- **أدلة لايف من G3:** ملف PDF حقيقي (316 KB) صُدّر ونُشر كـ**رسالة 28** في توبيك `04-Advanced-Software-Eng`؛ معرّفات تدقيق **97–106**؛ محادثة خارج قائمة السماح = **خروج 3 بلا أي نداء شبكة**.
- **ثلاثة عيوب اكتشفها التشغيل الحيّ ولم تكتشفها 250 اختبار:** (`VAULT_ROOT` off-by-one) · (`file://` أُرسل كـ JSON بدل multipart) · (`_emit()` ينهار على cp1252 مع أي عربي/إيموجي).

## 4. ما هو مكتوب لكن **غير مُشغّل لايف** ⏳ (قرار واعٍ)

- وسائط النشر: `publish --kind` → `sendPhoto/Video/Audio/Voice/Animation/Sticker` + `--caption`/`--html`.
- `media_group`: `--file` متكرر → `sendMediaGroup` واحد.
- `forward` / `copy` مع `--from-chat`.
- السبب: **أي أمر أو طريقة Bot API جديدة تبقى خارج الجروب حتى G5** (ضمانة SP3). مُتحقَّق منها بـ `--dry-run` فقط.
