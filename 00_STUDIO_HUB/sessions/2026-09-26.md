## 3. Native IndexedDB Client Storage Engine (`QuizVault`)

- Created `91_Dashboard/static/quiz-vault.js` (zero external dependencies):
  - Database: `MasterStudioQuizDB` (v1) with `navigator.storage.persist()` durability request.
  - Object Stores:
    1. `quizzes` (keyPath: `key` = `${subject_id}/${quiz_id}`, indexed by subject and semester).
    2. `in_progress` (keyPath: `key` = `${subject_id}/${quiz_id}`).
    3. `bookmarks` (keyPath: `k` = `${subject_id}/${quiz_id}#${index}`).
    4. `submission_queue` (keyPath: `submission_uuid`, indexed by status).
  - Resilient graceful fallback to `localStorage` if IndexedDB is disabled.

## 5. Automated Two-Way Sync & Queue Flushing

- **Write-Ahead Offline Telemetry Queue:**
  - `submitTelemetry()` writes submission payloads into `QuizVault.enqueueSubmission(payload)` first.
  - Posts to `POST /api/quiz/submit`. Upon HTTP 200, immediately dequeues the item.
  - If offline or unreachable, retains the payload in the IndexedDB queue with toast feedback: `تم الحفظ في ذاكرة الهاتف (سيتم المزامنة تلقائياً عند الاتصال)`.
- **Auto-Flush Background Synchronization:**
  - 15-second heartbeat and `window.addEventListener('online', ...)` trigger queue flushing upon connectivity.
  - Automatically drains pending attempts to `/api/quiz/submit` and displays toast: `تمت مزامنة N نتيجة كويز تلقائياً مع ماستر ستوديو`.

## 7. Telegram Direct-Open, Web Share Target & LAN PC Agent Sync

- **Telegram Direct-Open via File Handling API (`manifest.json` + `quiz.js`):**
  - Registered `file_handlers` for `.json` and `.msquiz`.
  - Implemented `window.launchQueue.setConsumer()` in `quiz.js`: tapping a quiz JSON sent over Telegram or in Android File Manager prompts "Open with MCS Quiz", loads it in 0ms, normalizes it, saves to `QuizVault`, and launches the quiz immediately.
- **Web Share Target API (`manifest.json` + `sw.js` + `app.py`):**
  - Registered `share_target` accepting `quiz_files`.
  - Offline: Service Worker intercepts `POST /quiz?shared=true`, caches quizzes in `/api/internal/shared-quizzes`, redirects to `/quiz?from_share=1`, and `quiz.js` imports them into `QuizVault`.
  - Online: Flask `POST /quiz` receives multipart files, injects them into DOM, and `quiz.js` auto-imports them.
- **Bi-Directional LAN PC Agent Synchronization (`POST /api/quiz/import`):**
  - Added `POST /api/quiz/import` to `91_Dashboard/app.py`: when the phone is on the same local Wi-Fi/LAN as the PC, any quiz received on mobile (e.g. from Telegram) is automatically synced and saved into the PC subject vault (`01_Semester_X/<subject>/07_Quizzes_&_Anki/<quiz_id>.json`).
  - Telemetry submissions from mobile (`POST /api/quiz/submit`) continuously sync student attempts to `00_STUDIO_HUB/sessions/YYYY-MM-DD.md` and `quiz_history.json`.
- **Split-Screen Drag & Drop:**
  - `initDragAndDrop()` supports recursive folder inspection (`webkitGetAsEntry`) when dragging from Android split-screen or desktop file managers directly onto the PWA window.
