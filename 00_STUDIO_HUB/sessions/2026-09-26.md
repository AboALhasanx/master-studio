## 3. Native IndexedDB Client Storage Engine (`QuizVault`)

- Created `91_Dashboard/static/quiz-vault.js` (zero external dependencies):
  - Database: `MasterStudioQuizDB` (v1) with `navigator.storage.persist()` durability request.
  - Object Stores:
    1. `quizzes` (keyPath: `key` = `${subject_id}/${quiz_id}`, indexed by subject and semester).
    2. `in_progress` (keyPath: `key` = `${subject_id}/${quiz_id}`).
    3. `bookmarks` (keyPath: `k` = `${subject_id}/${quiz_id}#${index}`).
    4. `submission_queue` (keyPath: `submission_uuid`, indexed by status).
  - Resilient graceful fallback to `localStorage` if IndexedDB is disabled.

## 5. Automated Two-Way Sync & Queue Flushing

- **Write-Ahead Offline Telemetry Queue:**
  - `submitTelemetry()` writes submission payloads into `QuizVault.enqueueSubmission(payload)` first.
  - Posts to `POST /api/quiz/submit`. Upon HTTP 200, immediately dequeues the item.
  - If offline or unreachable, retains the payload in the IndexedDB queue with toast feedback: `تم الحفظ في ذاكرة الهاتف (سيتم المزامنة تلقائياً عند الاتصال)`.
- **Auto-Flush Background Synchronization:**
  - 15-second heartbeat and `window.addEventListener('online', ...)` trigger queue flushing upon connectivity.
  - Automatically drains pending attempts to `/api/quiz/submit` and displays toast: `تمت مزامنة N نتيجة كويز تلقائياً مع ماستر ستوديو`.
