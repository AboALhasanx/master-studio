## 6. Authoring lesson — the verbatim label must live INSIDE the quote block

**Student-caught defect (rendered PDF):** I attached a source label to a verbatim quote as a **standalone bold paragraph above** the quote, so the renderer drew the label **outside** the callout — a bold line over an empty-looking box.

- **WRONG:** `**Verbatim (Mall p.114):**` ⏎ blank ⏎ `> This model gets its name …`
- **RIGHT:** `> **Verbatim (Mall p.67):** *"At this stage, the customers are usually …"*` (label + quote on the same `>` line).

**Generalised rule:** any label bound to a blockquote (`Verbatim`, `Source`, `Note`, `المصدر`, `اقتباس`) must be **inside the `>` block on the same line as the quote** — never a bare paragraph above it. Recorded in project `MEMORY.md` §6 as a hard authoring law; student marked it **unforgivable unless recorded properly**.

- **Occurrences (left unfixed per student):** `Week_02_File_06_The_Spiral_Model.md` lines 49 & 55; `Week_02_File_08_Agile_XP_Scrum.md` lines 294 & 298; propagated into `Week_02_Master_Lecture.md` (≈ lines 2534, 2540, 3318, 3322) → visible in the merged PDF.
- **Why it was missed:** both forms look identical in raw markdown preview — the difference only appears in the rendered callout. Added a mechanical pre-delivery grep ("every `**Verbatim…**` line must start with `>`").
