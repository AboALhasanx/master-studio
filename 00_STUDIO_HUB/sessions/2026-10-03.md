## 2. الإصلاحات

### 2.1 فعل `edit` الحقيقي (ثغرة #1) — `human.py` + `cli.py`
- `HUMAN_VERBS` صار سبعة: `whoami chats read say sendfile edit login`.
- `CHAT_VERBS` صار يشمل `edit` → **الـallowlist تُطبَّق عليه**.
- `HumanRequest.message_id` جديد؛ `authorize()` يرفض `edit` بلا `--message-id` أو بلا `--text`.
- `TelethonGateway.edit_message(chat_id, message_id, text)` → `messages.editMessage` بـ`parse_mode="html"` (يعمل على الكابشن بخلاف `editMessageText` في Bot API).
- `edit` **خارج** `SEND_VERBS` عمداً: تعديل لا ينشئ رسالة، وتحديث كارت يجب ألا يُسكت إرسالاً حقيقياً.
- `_human_detail` يسجّل `message_id=… text=<الجديد>` — تيليجرام لا يحفظ تاريخاً، فالصف هو السجل الوحيد.
- الاختبارات: مجموعة الأفعال + 7 اختبارات نطاق (`TestEditVerb`) + اختبار المحوّل + اختبارا CLI + توثيق `--message-id` (يفرضه `test_every_human_flag_is_documented`).

### 2.2 `RETIRED_SUBJECTS` — الربط الوهمي (ثغرة #2)
- `registry.RETIRED_SUBJECTS = ("70-Exams-and-MCQ", "71-Progress-Analytics", "90-Toolbox")`.
- `seed()` **يمسح** أي إحداثيات قديمة على المفاتيح المتقاعدة (فتتحقق لأي تحميل مُبذّر).
- `resolve()` **يرفضها صراحةً** حتى لو أعاد أحدٌ ربطها يدوياً.
- **إصلاح البيانات الحيّة:** `90-Toolbox`/`71`/`70` صارت `chat_id=None thread_id=None` → `UnboundTopic`؛ المواد الست سليمة (84–89).
- الاختبارات: 3 اختبارات جديدة (تبقى مبذورة لكن لا تُحلّ · لا تُبعث يدوياً · `seed` ينظّف ويحفظ).

### 2.3 بوابة التحقق الدائمة (ثغرة #3) — `telegram/verify.py` + `tools/tg_verify.py`
- **النواة نقية:** `verify_topic(catalog, messages)` → `TopicReport`؛ بلا شبكة، فكل ثابت مُختبَر في CI (15 اختباراً).
- **القراءة:** `TelethonGateway.topic()` — Bot API لا يقرأ تاريخ توبيك ولا رسالته المثبّتة.
- الفحوصات: الكارت أول رسالة محتوى ومثبّت · يسمّي المادة والدكتور · سطر الجابتر الحرفي · كل ترتيب · الكتيّب المرفق · روابط الجابترات للرسائل المنشورة · لا رابط عاري · وجود كل جابتر ومصدر · ≥62 بايت لكل اسم.
- **قراءة فقط بالبناء**؛ يخرج `1` عند فشل و`5` بلا `--live`.
- **تحقق حيّ:** `ALL CHECKS PASSED` على المواضيع الستة (84–89).
