# ذاكرة البوابة (`00_STUDIO_HUB/telegram/`)

> **العقد (interface) بين بوابة تيليكرام وذاكرة الماستر ستوديو — ADR D14.**

هذا المجلد هو **الذاكرة الخاصة** لبوابة تيليكرام. الفكرة: بوابة تيليكرام
**طبقة مستقلة** داخل الماستر ستوديو — لها ذاكرتها المرسومة، لكنها **مربوطة**
بالذاكرة الأم بعقد صريح. **ليست معزولة كلياً، وليست مبعثرة بلا حدود.**

---

## 1. لماذا هذا المجلد؟

قبل D14 كانت البوابة تكتب في ذاكرة الماستر ستوديو مباشرة بلا حدود: لا مالك
واضح، ولا عقد. بعد D14:

- ذاكرة البوابة **هنا** — لا تُخلط بذاكرة المشروع.
- الاتصال بالذاكرة الأم يمرّ عبر **عقد معلن** (الجدول أدناه).
- نقل البوابة لمشروع آخر لاحقاً = نقل هذا المجلد معها.

## 3. العقد — مَن يكتب ماذا، ومَن يقرأ ماذا

| الاتجاه | مسموح؟ | القاعدة |
|:--|:--:|:--|
| البوابة → **هذا المجلد** | ✅ | حرّة تماماً (سجل النشر، الحالة، التفضيلات) |
| البوابة → `00_STUDIO_HUB/MEMORY.md` (الأم) | ❌ | **ممنوع مباشرة** — تمرّ عبر الوكيل |
| البوابة ← **هذا المجلد** | ✅ | تقرأ حرة |
| البوابة ← `00_STUDIO_HUB/MEMORY.md` (الأم) | ✅ | قراءة حرة (للسیاق: أي مواد، أي توبيك) |
| الوكيل → **هذا المجلد** | ✅ | يقرأ ويسجّل |

**السطر الذهبي:** البوابة **لا تكتب** في ذاكرة الماستر ستوديو الأم مباشرة.
لو احتجت تسجّل شي في ذاكرة الأم، الوكيل هو الوسيط.

## 4. الحدود مع الحالة الحيّة (`telegram/` في الكود)

| | `90_Shared_Toolbox/telegram/registry.json` + `gateway.db` | `00_STUDIO_HUB/telegram/` |
|:--|:--|:--|
| الدور | **حالة تشغيل** (روابط توبيكات، طابور، تدقيق) | **ذاكرة** (سجل، تفضيلات، حالة قابلة للقراءة) |
| النمط | آلي، SQLite/JSON | بشري + آلي، Markdown/JSON |
| الحالة | gitignored (D10) | مقصود مرفوع (سجل نظيف) |

**القاعدة:** `telegram/` تعرف *كيف* تنفّذ؛ `00_STUDIO_HUB/telegram/` تعرف
*ماذا حدث وماذا نريد*.

## 5. الواجهة البرمجية

`90_Shared_Toolbox/telegram/telegram_memory.py`:

```python
record_post(subject, message_id, kind, detail)   # يسجّل نشراً في السجل
last_state()                                     # يقرأ STATE.md → dict
append_log(text)                                 # يضيف سطراً للسجل اليومي
read_prefs()                                     # يقرأ TELEGRAM_MEMORY.md
set_state(**fields)                              # يحدّث STATE.md
```

كل كتابة ذرّية (write-temp → rename) — لا ملف مقطوع عند الانقطاع.
